# 快速上手

dataBasePro 是一款多数据源管理客户端,支持 **Kafka / MySQL / TiDB / PostgreSQL / ClickHouse / Elasticsearch / Redis** 的连接管理与常用操作。本篇帮助新用户快速建立第一印象。

## 新建连接

- 点击左侧连接树底部的「＋ 新建连接」按钮。
- 填写名称、地址与认证信息后保存,连接会出现在左侧树中,可随时编辑或删除。

## 浏览与查询

- 左侧连接树按数据源展示 Topic、消费组、数据库与表等节点,双击即可打开对应标签页。
- 顶栏「新建查询」按当前标签所属数据源打开对应的 SQL 控制台,支持语句执行与结果浏览。
- 顶栏「SQL文件」按钮展开全局右栏,统一管理 `.sql` 查询文件;编辑器内 ⌘S / Ctrl+S 可随时保存。

## 表管理

- 双击树上的表节点打开表浏览器,可分页浏览数据、查看结构,部分数据源支持单元格编辑。
